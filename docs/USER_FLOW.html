01Entry & Onboarding

Phone sign-in via SMS code. Invite codes deep-link in and prefill on the phone step.

flowchart TD
    A([Open Commons]) --> B{Signed in?}
    B -- No --> C[Enter phone number]
    C --> D[Enter SMS code]
    D --> E{Admin phone?}
    E -- Yes --> F[Admin choice]
    F --> G{Onboarding complete?}
    E -- No --> G
    B -- Yes --> G
    G -- No --> H[Pick neighborhoods]
    H --> I[Pick interests min 2]
    I --> J[Profile: name + avatar]
    J --> K[Accept guidelines]
    K --> L([Home / Feed])
    G -- Yes --> L

POST /auth/request-code · POST /auth/verify-code · POST /auth/redeem-code · GET·PATCH /auth/me · GET /neighborhoods

03Plan Lifecycle — the core loop

A plan is "looking-for" when any of date/time/place is flexible; otherwise standard. The host can lock it in to confirm.

flowchart TD
    New[Create plan] --> Fields[Venue / area / date-time / interests / visibility / spots / flyer]
    Fields --> Kind{Any field flexible?}
    Kind -- Yes --> LF[Looking-for plan]
    Kind -- No --> STD[Standard plan]
    LF --> Feed[Shows in Feed + Explore]
    STD --> Feed
    Feed --> Detail([Plan detail])
    Detail --> RSVP{RSVP}
    RSVP --> Going[I am in — going]
    RSVP --> Inter[Interested]
    Going --> Thread[In the group chat]
    Inter -. looking-for .-> Thread
    Detail --> Suggest[Suggest a time / idea]
    Detail --> GetThere[Get there — maps]
    Detail --> Share[Share]
    Detail --> HostQ{Am I the host?}
    HostQ -- Yes --> Host[Host controls]
    Host --> Lock[Lock it in — Confirmed]
    Host --> Time[Propose / apply time]
    Host --> Approve[Approve applicants]
    Host --> InviteN[Invite network]
    Host --> Transfer[Transfer host]
    Host --> Cancel[Cancel]
    Host --> Edit[Edit]
    Thread --> Chat([Group chat])
    Lock --> Happens([Event happens])
    Happens --> FB[Feedback: up/down + host tags]
    Happens --> Nudge[Network nudge: add people you met]

POST /plans · GET /plans/:id · PUT·DELETE /plans/:id/participation · /lock · /propose-time · /apply-time · /approve · /invite · /suggestions · /transfer-host · /cancel

04Messaging

Per-plan group chats plus a unified inbox of every chat you can reach (hosting / going / interested). In-plan chat still opens from the detail page.

flowchart LR
    Inbox([Messages inbox]) --> Row[Row per accessible plan chat]
    Row --> GC([Group chat])
    Detail([Plan detail]) --> GC
    GC --> Send[Send message — notifies others]
    Inbox -. unread total .-> Badge[Top-bar badge]

GET /conversations · GET /plans/:planId/conversation · GET·POST /conversations/:id/messages

05Social Graph

One-way network adds, invite codes for growth, and a post-plan nudge to add the people you actually showed up with.

flowchart LR
    Me([You]) --> Net[Network — one-way adds]
    Net --> Others[Other profiles]
    Others --> AddF[Add to network]
    Others --> MakeW[Make a plan with them]
    Me --> Codes[Invite codes x3 — SMS / share]
    Codes --> NewU[New user onboarding]
    Me --> NudgeAfter[Post-plan network nudge]
    NudgeAfter --> Net

GET /auth/network · POST /auth/friend-add|friend-remove · GET /auth/network-prompt · POST /auth/network-add|network-dismiss · GET /auth/invite-codes
